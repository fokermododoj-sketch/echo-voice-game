# ЭХО

Браузерная голосовая игра для одного или двух игроков. Послушай образец, повтори его в микрофон и сравни свой ритм, высоту и тембр с образцом. На сцене реагируют на звук два анимированных 3D-персонажа.

- **Мемные реплики** — пакет по умолчанию. В нём 24 выдержки из русской актёрской озвучки: короткие выкрики, замечания и вопросы, в которых нужно повторить интонацию и паузы. [Источники и лицензия](assets/voice/SOURCES.md)
- **Фонотека** содержит 84 образца в семи пакетах, в том числе 60 игровых звуковых эффектов. Каждый образец можно прослушать и сыграть отдельно.
- **Настройки матча** позволяют выбрать пакеты и сыграть 5, 10 или 15 раундов.
- **Микс испытаний** добавляет блиц, раунд на слух и раунды с двойным весом ритма, высоты или тембра. В обычном матче можно отдельно отключить словесные подсказки.

## Игра с другом

1. Откройте сайт у себя. Хозяин выбирает **С другом → Создать комнату** и отправляет приглашение другу в чат.
2. Друг открывает ссылку или вставляет код в **С другом → Войти по коду** и отправляет хозяину ответный код.
3. Хозяин вставляет ответный код и нажимает **Подключить друга → Начать матч**.
4. В каждом раунде оба прослушивают образец и записывают ответ. После этого хозяин переключает раунд. В конце можно сыграть реванш.

Записи в режиме для двоих передаются между браузерами через WebRTC. Для установления соединения используется публичный STUN-сервер Cloudflare. Нужна сеть, в которой возможно прямое соединение. Некоторые VPN, корпоративные сети и мобильные операторы требуют TURN-ретранслятор, которого в этой сборке нет.

## Запуск на компьютере

В PowerShell открой папку с этими файлами и запусти:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Затем открой [http://localhost:8000](http://localhost:8000). Для микрофона используй localhost или опубликованный сайт с HTTPS. Чтобы завершить локальный сервер, нажми Ctrl+C в PowerShell.

## Публикация на GitHub Pages

1. Создай пустой [публичный репозиторий GitHub](https://github.com/new), например `echo-voice-game`.
2. Загрузи файлы из этой папки в корень ветки `main`.
3. Открой **Settings → Pages**, выбери **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажми **Save**.
4. Когда сборка пройдёт, GitHub покажет адрес игры в **Settings → Pages**. У обычного проекта адрес выглядит как `https://ИМЯ.github.io/echo-voice-game/`.

[Официальное руководство GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
